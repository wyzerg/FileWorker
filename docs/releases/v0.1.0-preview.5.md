## FileWorker v0.1.0-preview.5

远程工作区预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 每个连接记住最后成功打开的远程目录，重启后恢复；支持前进、后退、上级和刷新。
  上次目录不可用时提示并尝试起始目录，网络错误不会触发回退循环。
- 双击连接直接使用已存凭据，已连接对象不重复连接；没有凭据或认证失败再手工输入。
  首次主机指纹仍须确认，指纹变化仍阻止连接。
- 更明显的绿点和「已连接」标识；移除每个连接的三点按钮，保留右键和当前连接菜单。
- 远程工具栏/右键：预览、下载、复制路径、新建文件夹、重命名、删除和属性。
  右键刷新只重新读取目录，不再通过 WebView Reload 丢失连接。
- 双击普通文件只读预览 UTF-8 文本/日志及 PNG/JPEG/GIF/WebP 图片；
  文本最多 1 MiB，图片最多 8 MiB/4000 万像素。HTML/SVG 只显示文本，不执行活动内容；
  无预览磁盘缓存、外部编辑器或保存回传。
- 新目录使用 `0700`，重命名不覆盖同名项；删除明确确认且仅删除普通文件或空目录，
  不递归、不进入回收站。未结束传输时禁止修改，原生队列也防止并发冲突。
- 修复自动认证失败后的凭据状态竞态和矮窗口布局，输入框保留系统文本操作菜单。

### 升级与回退

沿用 `preview.4` 的连接配置 v2、凭据绑定和安全存储，无新增配置迁移。
新增本地目录记忆键仅含端点元数据和路径；修改端点、起始目录或删除连接会清除对应记忆。
回退 `preview.4` 无需转换数据，旧版忽略该键；回退更早 v1 应用仍需先保留现用配置，
按原有说明使用迁移备份。已执行的服务器文件修改或下载不会随应用回退撤销。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.5-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，使用新包中的 `FileWorker.app`。
3. 完整 ad-hoc 签名不是 Developer ID 签名，本包未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，在「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。不关闭系统整体安全检查，不批量移除下载文件隔离属性。

ZIP 大小 `5,384,975` 字节，SHA-256：

```text
b7e8a3240db9fbed4a7989c79da76d1fc39eba38922a7079af906ab1acee18e9
```

### 验证与限制

- `192` 项前端、`25` 项 Playwright、`101` 项完整 Rust 测试通过，
  包含 `35` 项真实隔离协议和 `1` 项随机 Keychain 往返。
- C 依赖实际插桩的 ASan 下 `35` 项协议测试通过，未启用泄漏检测；
  `11` 项打包回归、类型、格式、Clippy、生产前端和优化应用构建通过。
- 同一 ZIP 解压应用实测目录恢复、保存密码直连、前进/后退、右键刷新不掉线、
  文本/PNG 预览、属性、私有目录创建、重命名同名保护及重试、删除确认和取消、
  工具栏下载与 SHA-256 一致性。实际删除由协议测试验证，未提交原生删除确认。
  测试使用生成的回环服务和隔离 HOME，测试凭据与环境清理后真实用户配置未变。
- 签名校验通过不等于 Gatekeeper 信任通过；本轮未做浏览器下载后的首次启动授权。
  旧标签和附件保留，不静默替换。仍为实验性预发布，不是正式稳定发行版。
- 实际原生环境为 macOS `26.5.2` Apple Silicon；最低系统元数据为 `12.0`，
  但 macOS 12、Intel Mac、Windows 和 Linux 仍未实测。
- Finder 错误投放目标、浏览器首次启动、安装升级/回退仍待原生验收。
  Finder 拖出、目录递归传输、暂停/恢复、断点续传和跨重启队列恢复尚未实现。
