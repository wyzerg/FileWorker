## FileWorker v0.1.0-preview.9

本地加密凭据预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 密码、私钥文件口令和粘贴私钥改为应用自己的本地加密存储，不再调用 macOS Keychain。
  勾选记住且认证成功后才保存，下次双击连接可自动使用，不需要额外解锁密码。
- 使用随机本机密钥和 XChaCha20-Poly1305，每次保存使用新 nonce，密文绑定连接身份。
  前端不接收已保存秘密，密码和私钥内容不写入连接配置。
- 凭据操作支持跨进程锁、原子替换和读取上限；锁最多等待两秒。
  Unix 拒绝不安全权限、链接和非普通文件，密钥异常或密文损坏不自动重置或覆盖原条目。
- 修复首次初始化中断后不能重试保存，以及写入后报错、取消认证时遗漏凭据恢复的边界。
  修正协议测试夹具的无权限目录清理，测试结束不遗留生成文件。
- 保留多连接、后台传输、目录记忆、连接分组、远程多选删除、紧凑工具栏与明暗外观。

### 升级与回退

1. 完成或取消传输并退出旧程序，使用新包中的 `FileWorker.app`。
2. 旧 Keychain 条目不会读取、迁移、删除或作为后备。已有连接需手动重新输入一次密码、
   私钥口令或粘贴私钥，再勾选记住；保存成功后可自动连接。
3. 连接配置 v2、身份散列、主机信任、目录记忆和外观格式不变。
   忘记、删除连接或更换认证身份只清理新库中的对应条目，不影响其他连接。
4. 回退 `preview.8` 使用其原有 Keychain，新库不会同步回旧版。
   服务器文件改动和已完成传输不会随应用回退撤销。

### 安全取舍

**自动解锁的密钥也存放在本机，能读取密钥和密文的人就能解密。**
它不是系统钥匙串级别的隔离，不防当前用户、管理员或本机恶意程序，没有主密码或硬件绑定。
数据位于应用数据目录下的 `credentials-v1/`，Unix 目录/文件为 `0700`/`0600`。
不要上传 Git、云盘或公开分享；备份须一起保护密钥和密文，丢失密钥无法找回秘密。

凭据存储层不再依赖 macOS，**不代表 Windows/Linux 应用已完成适配或验收**。
Windows 用户目录 ACL、原生构建与安装仍需后续实测。SSH 主机指纹核对没有取消。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.9-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压。ZIP 未加密，不需要解压密码。
3. 本包使用免费完整 ad-hoc 签名，不是 Apple Developer ID 分发签名，未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，到「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。系统首次打开授权仍可能要求本机登录密码，
   与本次移除的凭据钥匙串提示不同。不关闭系统整体安全检查，不批量移除隔离属性。

ZIP 大小 `5,388,471` 字节，SHA-256：

```text
e369a7208e96a2312d8efc9d11f7ff049bcf5023aef2f9ee97ee5c9ce766d101
```

### 验证与限制

- `250` 项前端（默认及随机顺序 seed `72611`）、`36` 项 Playwright、
  `135` 项核心 Rust（含 `52` 项隔离协议及夹具回归、`21` 项本地存储测试）、
  `3` 项 Tauri 文件入口测试、`11` 项打包回归、类型、格式、工作区 Clippy 和锁定依赖优化构建通过。
- 覆盖密码、私钥文件口令和粘贴私钥的保存/重启复用、忘记、身份变更、非致命保存失败，
  篡改、错误账户/密钥、密钥缺失、并发进程、锁超时、权限与链接拒绝。
  两个审查问题和测试清理问题均先复现失败，再修复并重新跑完整测试。
- 本地 ZIP 完整性、SHA-256、解压后严格签名、标识、`0.1.0` 基础版本和 `arm64` 架构已校验。
  保留所有旧标签和附件，不自动替换已安装的应用。公开附件结果另见仓库发布验证记录。
- 测试使用专用临时目录、回环 SFTP 和浏览器 IPC，不访问用户服务器、密钥或应用凭据，
  不执行系统钥匙串测试。未重跑 ASan、原生 GUI/Finder、浏览器首次启动、Gatekeeper、
  安装升级及回退，不用协议或浏览器结果替代这些原生验收。
- 最低系统元数据仍为 macOS `12.0`，macOS 12、Intel Mac、Windows、Linux 未实测。
  Finder 拖出、目录递归传输、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  本包为实验性预发布，不是正式稳定发行版。
