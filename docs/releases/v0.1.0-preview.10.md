## FileWorker v0.1.0-preview.10

连接失效检测与操作超时修复预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 每 30 秒检查所有已连接会话，返回应用或页面恢复可见时立即复查；
  使用原连接上的只读 SFTP 请求确认服务器回应，不重新认证、不刷新目录或改动路径。
- 掉线或超时后清除对应连接的绿灯、旧文件列表与等待状态，提示具体连接及重连；
  一个服务器失效不影响其他连接。旧检查和旧目录结果不会使新会话失效。
- 修复 SFTP「无连接」「连接丢失」被当作文件或目录错误的问题；
  普通权限、路径错误仍不会误判为掉线。
- 浏览、预览、属性、远程修改和检查默认共用 15 秒整次请求期限，排队时间也计算在内。
  尚未执行的排队请求到期后不再发送；正在执行的请求到期则关闭对应会话，释放其他等待。
  忙碌连接跳过健康检查，大文件独立传输仍使用网络等待超时，不受 15 秒总传输时长限制。
- 不自动重连，不自动重试删除、重命名、上传等修改。服务器可能已经执行但回包丢失，
  必须重连并刷新确认实际结果，不能把超时当成“肯定没执行”。

### 升级与回退

1. 完成或取消传输并退出旧程序，使用新包中的 `FileWorker.app`；不自动替换已安装的副本。
2. 从 `preview.9` 升级不需要重新输入已记住的凭据，配置、主机信任、目录记忆及外观格式不变。
   从更早的 Keychain 版本升级，仍需手动输入一次并重新勾选记住；旧条目不读取、迁移或删除。
3. 可以回退 `preview.9`，无需迁移数据，但会恢复旧版连接检测行为。
   回退程序不能撤销服务器上已发生的文件修改。
4. 本地加密凭据继续使用同机保存的自动解锁密钥，能读密钥和密文的人可解密，
   不等同于系统钥匙串隔离，没有主密码；请勿公开分享整个应用数据目录。

### 下载与首次打开

1. 下载 ZIP 与同名 `.sha256`，在下载目录执行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.10-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压。ZIP 未加密，不需要解压密码。
3. 使用免费完整 ad-hoc 签名，未使用 Apple Developer ID 分发签名，未做 Apple 公证。
   首次打开仍可能被系统阻止。确认来源和校验值后，到「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认；系统授权可能要求本机登录密码。
   不关闭系统整体安全检查，不批量移除隔离属性。

ZIP 大小 `5,406,276` 字节，SHA-256：

```text
4681ffc8bfa2e9639561261f0a8491c6953062465d2f5739614785c064507aa6
```

### 验证与限制

- `273` 项前端（默认及随机顺序 seed `72611`）、`37` 项 Playwright、
  `146` 项核心 Rust（含 `61` 项协议/夹具回归、`21` 项本地存储测试）、
  `3` 项 Tauri、`11` 项打包回归、类型、格式、Clippy 和锁定依赖优化构建通过。
- 连接状态误分类、整次操作期限和排队未计时均先复现失败，再修复。
  隔离协议验证空闲断开、无响应、忙碌跳过、精确会话关闭、多连接隔离、
  新旧会话交接、排队期限，以及服务器执行修改但回包丢失时请求仅发送一次。
  浏览器验证后台绿灯取消、当前会话与列表保留，无自动重连。
- 本地归档完整性、SHA-256、解压后严格签名、标识、基础版本及 `arm64` 架构校验通过。
  测试使用专用临时目录、回环服务、内存凭据及浏览器 IPC，不访问用户服务器、密钥或应用凭据。
- **未进行真实隔夜放置或系统睡眠/唤醒验收。** 休眠期间不能检测网络；
  恢复后依靠焦点/可见性事件或下一次定时检查复查，模拟事件不等同于系统级验收。
  本轮也未重跑 ASan、原生 GUI/Finder、浏览器首次启动、Gatekeeper、安装升级或其他平台。
- 最低系统元数据仍为 macOS `12.0`，macOS 12、Intel Mac、Windows、Linux 未实测。
  Finder 拖出、目录递归、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  这是实验性预发布，不是正式稳定发行版。
