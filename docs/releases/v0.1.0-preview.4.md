## FileWorker v0.1.0-preview.4

连接管理与分组预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由 Git 标签和文件名区分。

### 本次更新

- 可选单层连接分组：创建、改名、删除、展开和折叠；删除组保留连接和凭据。
  支持未分组，折叠状态重启保留。
- 连接右键和更多菜单：连接、编辑、复制、忘记凭据、删除，不为打开菜单切换会话。
- 同一表单直接输入密码、选择私钥文件或粘贴私钥，支持独立口令；
  提供测试连接、仅保存配置、保存并连接。
- 显示实际已存凭据状态，可更换、返回或忘记；切换和认证失败保留本次输入。
  明确勾选记住并认证成功后才保存到 macOS Keychain，不写配置或浏览器存储。
- 测试连接与当前浏览会话隔离，不保存草稿或密码；首次连接仍须确认主机指纹。
- 完善配置删除、认证身份变更和迟到凭据保存的协调，防止遗留旧凭据；
  改名、移动分组和默认目录修改保留当前会话。
- 标题栏「文件工作区」支持拖动，修复菜单、弹窗叠加和长私钥表单交互边界。

### 升级与回退

配置文档升级为 v2。读取 v1 不修改文件；首次有效修改前，应用创建原字节私有备份
`profiles.v1.backup.json`，已有备份不会覆盖。已有密码及文件私钥的凭据绑定不变。
配置文件仍不包含密码、私钥内容或口令，粘贴私钥的秘密仅用于当前会话或明确选择的
系统安全存储。

回退旧版前先结束传输并退出，另存当前 v2 配置，再从 v1 备份恢复。
旧应用不能直接读取 v2；备份不含迁移后新增、修改的连接和分组。
已经传输的文件不自动回滚，不以旧备份覆盖当前数据来保留新改动。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.4-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，将新包中的 `FileWorker.app` 放到应用程序目录。
3. 本包为完整 ad-hoc 签名，不是 Developer ID 签名，未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，在「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。不关闭系统整体安全检查。

ZIP 大小 `5,342,574` 字节，SHA-256：

```text
187651ed0fa5bd07a618296fb2797c75bc272b9d65136f35abc5313a5329fd6e
```

### 验证与限制

- `161` 项前端、`23` 项 Playwright、`93` 项完整 Rust 测试通过，
  包含 `31` 项真实隔离协议和 `1` 项随机 Keychain 往返。
- C 依赖实际插桩的 AddressSanitizer 下 `31` 项协议测试通过，未启用泄漏检测；
  `11` 项打包回归、类型、格式、Clippy、生产前端及优化应用构建通过。
- 同一 ZIP 解压应用原生实测密码测试/连接/记住/重连、加密私钥文件、
  粘贴私钥、分组改名/折叠持久化和标题栏拖动；本轮测试环境和凭据已清理。
- 完整签名校验不等于 Gatekeeper 信任通过；本轮未补做该版本的浏览器下载首次启动，
  不承诺无提示运行。旧标签和附件均保留，不静默替换。
- 实际验收为 macOS `26.5.2` Apple Silicon；最低系统元数据为 `12.0`，
  但 macOS 12、Intel Mac、Windows 和 Linux 仍未实测。
- 本轮不重做 Finder 原生拖入；既有证据见仓库验收记录。Finder 错误投放目标、
  下载授权和安装升级/回退仍待原生验收。
- Finder 拖出、目录递归、暂停/恢复、断点续传和跨重启队列恢复尚未实现，
  不是正式稳定发行版。
