## FileWorker v0.1.0-preview.11

工作区交互改进预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 本地普通文件可以直接拖到远程文件列表上传，远程也可以拖回本地下载。
  macOS 双栏内部改用窗口内指针拖动，修复真实窗口只有拖动开始、文件没有入队的问题。
  支持可见多选，显示文件名或数量；目标是另一栏已打开的目录，放到目录行也不会进入该子目录。
  Finder 拖入仍保留原生通道，不启用 Finder 拖出、文件夹或符号链接传输。
- 队列三个视图均最新任务置顶，按加入顺序倒序显示；重试保留原位置，
  不改变实际调度、并发或同名弹窗处理顺序。
- 已完成、失败、取消或跳过的每条记录均可单独移除。只移除内存记录，不删除源/目标文件；
  移除后不能再从该记录重试。运行、排队、取消中及同名待处理须先取消并等待结束。
- 左侧栏边界可以拖动，右侧本地、远程、工具栏和队列一起伸缩。
  松开后记住宽度，双击恢复默认；窗口变窄时临时限制宽度，放大后恢复原偏好。
  无效的继续扩宽不会覆盖偏好，Escape 或失焦会放弃正在进行的调整。
- 工具栏按文件栏实际宽度收纳到更多菜单，侧栏加宽也不会将筛选框挤窄或增加一行；
  窄视口沿用侧栏抽屉和本地/远程切换。

### 升级与回退

1. 完成或取消传输并退出旧程序，使用新包中的 `FileWorker.app`；不自动替换已安装副本。
2. 从 `preview.10` 升级无需迁移配置或重新记住密码，主机信任、目录记忆及外观格式不变。
   新增独立 WebView 偏好 `fileworker.sidebar-width.v1`，不写连接配置，旧版忽略。
3. 退出后可以回退 `preview.10`，但恢复旧拖动、队列顺序与固定侧栏行为。
   队列仍不跨重启保存；回退不能撤销已传输文件或服务器上的文件修改。
4. 凭据继续使用本机加密库，不访问钥匙串。自动解锁密钥与密文在同一设备，
   能读取两者的人可以解密，不等同于系统凭据库隔离；请勿公开分享应用数据目录。
   从旧 Keychain 版本升级仍需手动输入一次再记住，旧条目不读取、迁移或删除。

### 下载与首次打开

1. 下载 ZIP 与同名 `.sha256`，在下载目录执行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.11-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压。ZIP 未加密，不需要解压密码。
3. 免费完整 ad-hoc 签名不是 Apple Developer ID 分发签名，也没有 Apple 公证。
   首次打开仍可能被系统阻止。确认来源与校验值后，到「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认；系统授权可能要求本机登录密码。
   不关闭系统整体安全检查，不批量移除隔离属性。

ZIP 大小 `5,410,631` 字节，SHA-256：

```text

```

### 验证与限制

- `318` 项前端（默认及随机顺序 seed `72611`）、`48` 项 Playwright、
  `153` 项核心 Rust（含 `62` 项协议/夹具与 `21` 项本地存储）、`3` 项 Tauri、
  `11` 项打包回归、类型、格式、Clippy 和锁定依赖的 macOS arm64 优化构建通过。
- 隔离 HOME 与回环 SFTP 原生实测单文件、多选上传及反向下载，源/目标 SHA-256 一致；
  原生观察队列新任务置顶、侧栏鼠标/键盘调整及重启恢复。
  协议另验证运行中移除旧记录不影响工作线程取消与临时文件清理，不删除源或目标文件。
- 最终同一 ZIP 解压应用复验多选拖动上传与反向下载，源/目标哈希一致，
  侧栏鼠标拖动、键盘调整和双击复位通过；完整签名、归档、标识、基础版本和架构校验通过。
  取消拖动后第一次目录/修饰键点击失效先由三条失败回归复现，再修复并重跑全部前端与界面。
- 明暗主题、宽/窄桌面与移动视口的工具栏、双栏对齐、侧栏伸缩及队列操作通过浏览器回归。
  浏览器使用模拟 IPC，不代替原生验收；原生 GUI 本轮未点击记录移除按钮。
  具体证据与隔离边界见 `docs/acceptance/2026-11-16-workspace-interactions.md`。
- 本轮未重新执行真实 Finder 拖入、ASan、隔夜放置、系统睡眠/唤醒、
  浏览器首次启动、Gatekeeper、安装升级回退或其他平台验收。
  Finder 错误投放边界仍需专门验收，不把历史记录或模拟事件当作本轮证据。
- 最低系统元数据仍为 macOS `12.0`，macOS 12、Intel Mac、Windows、Linux 未实测。
  目录递归、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  这是实验性预发布，不是正式稳定发行版。
