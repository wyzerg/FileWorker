## FileWorker v0.1.0-preview.7

紧凑工作区与明暗配色预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 本地和远程均将筛选、隐藏文件切换及操作图标合为 `36` 像素单行，
  比原来节省 `40` 像素，继续保持路径、工具栏、列表表头与页脚对齐。
- 窄窗将复制路径、重命名和属性收进「更多文件操作」，保留筛选宽度和当前多选目标，
  不增加工具栏行数。右键后取消勾选文件会关闭旧菜单，后续删除只处理仍选中的项目。
- 远程标题旁的小箭头改为扳手「连接设置」，菜单从实际点击的按钮下方打开，
  支持重复点击关闭和按 Escape 返回触发按钮。
- 全局提示移到现有底部状态栏，不再压缩文件区；长消息可展开、滚动和选择复制，
  支持 Escape、点击外部、再次点击收起或关闭。
- 暗色使用中性石墨灰、柔和灰白文字和低饱和青绿，保留钢蓝远程标识与琥珀文件夹；
  亮色使用柔和浅灰文件区。首屏与运行时背景一致，已有明暗或跟随系统偏好继续生效。

### 升级与回退

沿用连接配置 v2、已保存凭据、目录记忆和外观偏好，无数据迁移。
退出正在运行的 FileWorker 后，用新包中的 `FileWorker.app` 替换旧应用；
不要删除原有连接配置或钥匙串条目。本次发布不会自动替换正在运行的程序。
回退 `preview.6` 无需转换配置，但恢复旧工具栏、通知位置和配色。
服务器上已经执行的创建、重命名、删除或传输不会随应用回退撤销。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.7-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，退出旧程序，再使用新包中的 `FileWorker.app`。ZIP 未加密，不需要解压密码。
3. 本包使用免费完整 ad-hoc 签名，不是 Apple Developer ID 分发签名，未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，在「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。系统授权可能要求本机登录密码，这不是解压密码。
   不关闭系统整体安全检查，不批量移除下载文件隔离属性。

ZIP 大小 `5,387,158` 字节，SHA-256：

```text
e34ac7717998b34807b5b42137135282f06c0ecfb0fbdc944064219f14c7a84f
```

### 验证与限制

- 本次重新通过 `217` 项前端、`35` 项 Playwright、`68` 项默认 Rust、
  `11` 项打包回归，类型、格式、Clippy 及锁定依赖的生产前端和优化应用构建。
- 界面回归覆盖明暗主题、`1473/1280/800/390` 像素宽度与 `480` 像素矮窗，
  包含双栏对齐、通知不改变列表高度、长消息、菜单定位、重复点击关闭、多选目标与焦点返回。
  已检测的普通、次要、选中行及通知文字对比度均不低于 `4.5:1`。
- 本地 ZIP 完整性与 SHA-256 一致，打包脚本解压后校验完整签名、标识、基础版本和架构；
  不将签名通过等同于 Gatekeeper 信任通过。
- 公开发布后，无认证回读 ZIP 与校验文件，与本地产物逐字节一致；
  公开 ZIP 的 SHA-256、完整性与解压后的严格签名、标识、基础版本和架构再次校验通过。
  程序下载与解压不代替浏览器、Finder 或下载首次启动验收。
- 本次未重跑默认跳过的 `32` 项真实协议、`1` 项随机 Keychain 或 ASan，
  也未对新包重做原生操作、Finder 拖入、浏览器下载后首次启动、安装升级及回退。
  浏览器夹具不访问用户服务器或钥匙串，不能替代原生验收。
- 最低系统元数据仍为 macOS `12.0`，但 macOS 12、Intel Mac、Windows 和 Linux 未实测。
- Finder 拖出、目录递归传输、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  旧标签及附件保留，本包仍为实验性预发布，不是正式稳定发行版。
