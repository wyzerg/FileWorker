## FileWorker v0.1.0-preview.2

安装说明更新（2026-11-05）：此历史包仅有链接器临时签名，缺少完整应用资源签名，
浏览器下载后可能显示“已损坏”。推荐改用修正签名封装的 `v0.1.0-preview.3`。
旧标签、安装包与 SHA-256 保持原样，不替换历史附件。

实验性预发布，提供 macOS Apple Silicon 的优化 `.app.zip`。

### 本次改进

- 遇到同名文件直接弹框，显示文件名和目标路径，可选择跳过、覆盖或保留两份。
- 多个冲突逐个处理，不叠加连接或认证弹窗。
- 关闭表示稍后处理，当前冲突不因轮询反复弹出；保留队列中的手动处理入口。
- 提交期间阻止重复点击，失败时保留弹框和错误，成功后才继续下一项。
- 不默认覆盖已有文件，不修改连接配置、凭据或后端文件提交语义。

### 下载与安全

- 平台：macOS Apple Silicon（`arm64`）；实际验收 macOS `26.5.2`。
- 最低系统元数据：macOS `12.0`，不代表已在 macOS 12 实测。
- 未使用 Apple Developer ID 分发签名，未公证，首次打开可能出现系统安全提示。
- 应用内版本仍为 `0.1.0`，预发布序号由 Git 标签区分。
- Windows、Linux 和 Intel Mac 不提供二进制或支持承诺。
- 压缩包配有 SHA-256 文件；不是正式稳定发行版。

### 验证与限制

- `107` 项前端测试、`19` 项 Playwright、`30` 项默认 Rust 测试、类型、格式和 Clippy 通过。
- debug 和优化 `.app` 构建通过；优化 ZIP 解压后实测真实 SFTP 自动同名提示与连续处理。
- 真实 Finder 多文件上传与保留两份已在前一预发布包上实测，原件和副本 SHA-256 一致。
- 发布后补验（2026-11-05）：本包真实 Finder 混合普通文件与文件夹、符号链接均
  整批拒绝，队列和远端无写入；正常对照上传 SHA-256 一致，测试环境已清理。
  不将模拟事件视为 Finder 验收；错误投放目标仍待原生验收。
- Finder 拖出、目录拖入、目录递归传输、暂停/续传、跨重启队列恢复未实现。
- 完整协议套件与 ASan 本轮没有重跑；安装、升级、最低系统及签名公证仍待验收。

### 回退

结束传输并退出后可改用 `v0.1.0-preview.1`，连接配置无需迁移。
已传输的文件不会自动回滚。详细使用边界与验收记录见仓库 README。
