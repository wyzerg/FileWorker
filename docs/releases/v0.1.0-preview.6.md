## FileWorker v0.1.0-preview.6

双栏布局与批量删除修复预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 本地和远程均提供文件操作工具栏，标题、路径、筛选、工具栏、列表表头及页脚对齐；
  连接或断开服务器不再改变远程列表起始位置。
- 本地上传和目录选择移至操作工具栏；窄视口切换本地、远程时保留完整工具栏。
- 远程多选文件后，可通过右键或工具栏删除。确认前列出数量和完整路径，
  取消不发送删除请求；确认后按清单逐项执行并显示结果。
- 部分项目因权限或非空目录等原因失败时，继续处理其他项目并刷新成功项；
  「重试失败项」只提交失败路径，不重复删除成功项，多项完成后保留结果供核对。
- 防止重复提交；会话切换、断开或卸载后不继续删除剩余项目。
  中途出现传输或原生操作占用时停止后续请求，显示未执行项。

删除仍仅限普通文件或空目录，不递归、不进入回收站、不处理根目录或符号链接。
批次不是整批事务，部分成功不会自动回滚。断网或超时后须重连、刷新，确认服务器实际结果；
不会自动重试结果不明的请求。

### 升级与回退

沿用现有连接配置 v2、凭据绑定及目录记忆，无数据迁移。
退出正在运行的 FileWorker 后，用新包中的 `FileWorker.app` 替换旧应用；
不要删除原有连接配置或钥匙串条目。本次发布不会自动替换正在运行的程序。
回退 `preview.5` 无需转换配置，但会恢复旧布局和单项删除入口。
服务器上已经执行的创建、重命名、删除或传输不会随应用回退撤销。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.6-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，退出旧程序，再使用新包中的 `FileWorker.app`。
3. 本包使用免费完整 ad-hoc 签名，不是 Apple Developer ID 分发签名，未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，在「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。不关闭系统整体安全检查，不批量移除下载文件隔离属性。

ZIP 大小 `5,386,360` 字节，SHA-256：

```text
62010b468de898f9fa360b205baa29d54de2656314b44a3716ae2df49334d5e2
```

### 验证与限制

- 本次重新通过 `211` 项前端、`30` 项 Playwright、`68` 项默认 Rust、
  `11` 项打包回归，类型、格式、Clippy 及锁定依赖的生产前端和优化应用构建。
- 界面回归覆盖明暗主题、长路径清单、`1473/800/390` 像素窗口及 `480` 像素矮窗，
  包含确认取消、逐项结果、部分成功后刷新、仅重试失败项、重复提交和生命周期中断。
- 本地 ZIP 完整性与 SHA-256 一致，打包脚本解压后校验完整签名、标识、基础版本和架构；
  不将签名通过等同于 Gatekeeper 信任通过。
- 本次未重跑默认跳过的 `32` 项真实协议、`1` 项随机 Keychain 或 ASan，
  也未对新包重做原生批量删除、浏览器下载后首次启动、安装升级及回退。
  浏览器夹具不访问用户服务器，不能替代原生验收；历史原生证据见此前验收记录。
- 最低系统元数据仍为 macOS `12.0`，但 macOS 12、Intel Mac、Windows 和 Linux 未实测。
- Finder 拖出、目录递归传输、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  旧标签及附件保留，本包仍为实验性预发布，不是正式稳定发行版。
