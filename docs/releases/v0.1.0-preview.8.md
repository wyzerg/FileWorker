## FileWorker v0.1.0-preview.8

多连接保持预发布，仅提供 macOS Apple Silicon（`arm64`）的 `.app.zip`。
应用内基础版本仍为 `0.1.0`，预发布序号由标签和文件名区分。

### 本次更新

- 切换连接只切换远程工作区，不再断开已连接的服务器；侧栏同时标记所有活动连接。
  双击已连接对象直接返回，不重复认证。
- 每个连接独立保留目录、路径输入、前进/后退历史、加载和错误状态。
  迟到响应只更新原连接；同路径文件不会跨服务器继承勾选、右键或删除目标。
- 浏览或连接其他服务器时，后台传输继续。队列显示连接名称，
  仍连接的后台任务可重试或手动处理同名冲突，始终使用任务原服务器。
  后台上传完成后，返回对应目录时补刷文件列表，不覆盖未提交的路径输入。
- 断开、删除或更改认证身份只影响目标连接，并检查其自身的未结束传输。
  退出应用先停止和清理传输，再关闭全部连接；停止后不接受新连接。
- 初次目录读取缓慢不会阻塞下一台服务器的认证。
  未完成的前台认证仍串行，切换离开时取消，不影响已经认证成功的其他连接。

### 升级与回退

沿用配置 v2、已保存凭据、主机信任、目录记忆和外观偏好，无数据迁移。
完成或取消传输并退出旧程序后，使用新包中的 `FileWorker.app`；不会自动替换已安装程序。
回退 `preview.7` 无需转换配置，但恢复单会话行为。
服务器文件修改和已完成传输不随回退撤销。
网络中断或服务器空闲超时仍可能断开，不提供自动重连或跨重启恢复会话。

### 下载与首次打开

1. 下载 ZIP 和同名 `.sha256`，在下载目录运行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.8-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，退出旧程序，再使用新包中的 `FileWorker.app`。
   ZIP 未加密，不需要解压密码。
3. 本包使用免费完整 ad-hoc 签名，不是 Apple Developer ID 分发签名，未做 Apple 公证。
   首次打开仍可能被系统阻止；确认来源和校验值后，到「系统设置 → 隐私与安全性」
   查找「仍要打开」，由本人确认。系统授权可能要求本机登录密码，这不是解压密码。
   不关闭系统整体安全检查，不批量移除隔离属性。

ZIP 大小 `5,389,768` 字节，SHA-256：

```text
2c2055a4bc12aa61e8053be7d3839fea350e5f8d847a8f8b2046673479eac15b
```

### 验证与限制

- `239` 项前端（默认及随机顺序 seed `72611`）、`36` 项 Playwright、
  `107` 项完整核心 Rust（含 `45` 项隔离真实 SFTP）、`3` 项 Tauri 文件入口测试、
  `11` 项打包回归、类型、格式、工作区 Clippy 和锁定依赖的优化构建通过。
- 明暗和 `1280/800/390` 像素多连接界面回归通过，检查双连接状态、后台队列、
  独立路径输入、目录补刷和仅断开目标；原有工具栏对齐、通知及文件操作回归通过。
- 本地 ZIP 完整性、SHA-256、解压后的严格签名、标识、`0.1.0` 版本和 `arm64` 架构校验通过。
  标签指向提交 `2a444ab`，附件先上传草稿并核对摘要，再公开为实验性预发布。
  无认证回读 ZIP 和校验文件，与本地产物逐字节一致；公开包再次通过归档和解压校验。
  `preview.7` 附件 ID、大小和摘要保持不变。程序下载和解压不能替代原生首次启动验收。
- 真实协议使用隔离回环服务和内存凭据，不访问用户服务器、密钥或真实应用凭据。
  本轮没有重跑真实 Keychain、ASan、原生 GUI 退出/Finder、浏览器首次启动、Gatekeeper、
  安装升级及回退，不能以协议或浏览器结果代替原生验收。
- 最低系统元数据仍为 macOS `12.0`，但 macOS 12、Intel Mac、Windows 和 Linux 未实测。
  Finder 拖出、目录递归传输、暂停/恢复、断点续传和跨重启队列恢复仍未实现。
  保留旧标签和附件，本包仍为实验性预发布，不是正式稳定发行版。
