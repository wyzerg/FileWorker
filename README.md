# FileWorker

开源双栏 SFTP 桌面文件工具，使用 Rust、Tauri 2 和 React 构建，具备跨平台技术基础。
并排浏览本地与远程目录，安全连接服务器，批量上传下载并跟踪每项任务的进度。
当前开发版支持安全连接 SFTP、双栏浏览、普通文件上传下载、双栏内部拖放和真实传输队列。
macOS 上已实现从 Finder 拖入普通文件到当前远程栏；Finder 拖出、目录拖入、
目录递归传输和断点续传仍未实现。

## macOS 预发布安装

当前推荐 `v0.1.0-preview.9` 的 macOS Apple Silicon `.app.zip`，以及同名
`.sha256` 文件。旧 `preview.1`、`preview.2` 缺少完整应用资源签名，浏览器下载后
可能显示“已损坏”；保留历史产物，但不再推荐安装。

新包使用完整 ad-hoc 临时签名，不需要付费开发者账号；这只保证签名封装完整，
不代表获得 Apple Developer ID 身份或完成公证，不能承诺下载后无提示直接打开。

1. 从本仓库 GitHub Releases 下载 ZIP 与校验文件，在下载目录执行：

   ```bash
   shasum -a 256 -c FileWorker-v0.1.0-preview.9-macos-arm64.app.zip.sha256
   ```

2. 校验成功后解压，将新包中的 `FileWorker.app` 放到应用程序目录。
   不要继续打开旧包解压得到的同名副本。
3. 首次打开若因无法验证开发者或未公证而被阻止，确认来源和校验值后，
   到「系统设置 → 隐私与安全性」查找该应用的「仍要打开」，由本人确认。
   不需要关闭系统整体安全检查。若没有该入口或仍显示损坏，请保留提示并反馈，
   不要对下载目录或系统批量移除隔离属性。

此前已用 Chrome 实际下载 `preview.3` 并在 Finder 解压，校验值一致、隔离标记保留，
解压应用的严格签名校验通过。下载后首次启动与系统授权仍待用户现场确认，
不能据此宣称 Gatekeeper 信任通过。实际完成范围见
[签名修复验收记录](docs/acceptance/2026-11-05-macos-preview-signing.md)。
`preview.5` 已校验归档和解压签名，并使用同一 ZIP 解压的应用完成原生工作区验收；

`preview.9` 已无认证回读公开 ZIP 与校验文件，内容与本地产物逐字节一致；
下载包的 SHA-256、ZIP 完整性与解压后的严格签名、标识、版本和架构检查通过，

## 平台边界

不是只能运行在 Mac，也不能把跨平台技术栈等同于当前版本已经支持所有平台：

| 平台 | 当前状态 |
| --- | --- |
| macOS Apple Silicon | 已实测浏览、连接、上传下载与开发版 `.app`；当前源码使用本地加密凭据库。 |
| macOS Intel | 尚未构建和验收，不提供支持承诺。 |
| Windows 桌面 | Tauri 具备平台支持，但本项目尚未验证原生构建、运行和安装包。 |
| Linux 桌面 | Tauri 具备平台支持，但本项目尚未验证发行版系统依赖、原生运行和安装包。 |

Windows/Linux 仍需完成本地路径与远程 POSIX 路径分离、构建入口、窗口行为和打包适配，
以及真实文件传输验收。当前构建入口调用 Bash，默认打包目标仅为 macOS `.app`，
不能把现有 macOS 启动步骤直接当作 Windows 安装说明。
凭据存储现已独立于系统钥匙串，使用同一套 Rust 本地加密文件实现；
Windows/Linux 的应用数据目录权限、原生构建和实际运行仍需分别验收。
本仓库不包含 Windows/Linux Release，后续只将实际构建、运行并验收的平台列为支持。

## 当前可用

- 真实本地目录浏览、路径输入、返回上级和原生目录选择。
- 按名称、大小、修改时间排序，筛选当前目录，切换隐藏文件。
- 本地与远程均将筛选、隐藏文件切换和操作图标合为一行，路径、操作栏和列表表头逐行对齐。
- 新建、编辑、复制和删除 SFTP 连接配置；连接支持右键菜单，保留工作区的当前连接菜单。
- 可选的单层连接分组，支持新建、改名、删除、展开和折叠；删除组仅将连接移回未分组。
- 配置原子写入，跨进程事务锁保护，拒绝密码和私钥口令等未知字段。
- SFTP 先握手并显示 SSH SHA-256 主机指纹；首次连接必须明确确认，
  已信任主机指纹变化时阻止连接。
- 直接输入密码、选择 SSH 私钥文件或粘贴私钥内容，可先测试再保存并连接；
  认证成功后可选择将密码、私钥口令或粘贴的私钥凭据加密保存在本机，下次自动使用。
- 双击连接可直接使用已保存的凭据，已连接对象不会重复连接；侧栏显示明显的绿点和「已连接」。
- 可同时保持多个服务器连接，切换时恢复各自的目录、路径输入和前进/后退历史；
  后台传输不中断，侧栏同时标记所有已连接服务器。
- 每个连接记住最后成功打开的远程目录，重启后恢复；支持后退、前进、上级、刷新、筛选和排序。
- 远程工具栏和右键菜单提供预览、下载、复制路径、新建文件夹、重命名、删除及属性。
- 远程文件支持多选批量删除，确认清单后逐项执行；保留每项结果，失败可单独重试，不重复删除成功项。
- 双击普通远程文件可只读预览有大小限制的 UTF-8 文本、日志和 PNG/JPEG/GIF/WebP 图片。
- 勾选、范围及键盘多选普通文件，上传到右栏目录或下载到左栏目录。
- 双栏内部拖放普通文件：本地拖到远程上传，远程拖到本地下载，目标栏显示放置状态。
- macOS Finder 可将一个或多个普通文件拖入远程文件列表，复用传输队列和冲突处理；
  目标是当前已经打开的远程目录，整批最多 256 个文件。
- 真实后台传输队列，显示字节进度、平均速度、预计剩余时间、状态、错误和清理警告。
- 单项取消、失败/取消后从头重试；遇到同名自动弹框，明确选择跳过、覆盖或保留两份。
- 默认同时传输 3 项，可调整为 1 到 6 项；每项使用独立且重新校验指纹的 SSH 连接。
- 网络操作有超时，待认证连接会主动过期关闭；支持取消、断开和迟到响应隔离。
  网络、认证和目录错误会显示给用户，不会伪装成空目录。
- 中文双栏界面、侧栏、传输区折叠和窄视口文件栏切换。
- 深色、浅色、跟随系统三种外观，自动保存选择；中性石墨灰与柔和浅灰配色统一覆盖表格、菜单和弹窗。
- 全局提示显示在现有底部状态栏，不挤占文件区；可展开完整内容或关闭。
- macOS 本地开发及 `.app` 打包。

暂停恢复、自动重试、断点续传、跨重启队列恢复、Finder 拖出、目录拖入、
目录递归传输和远程编辑后回传属于后续阶段。

## 双栏工作区

以下单行工具栏、扳手入口、底部通知与新配色已纳入 `v0.1.0-preview.7` 及后续发布包。
旧 `preview.6` 包含双栏对齐与批量删除，但仍使用原来的两行工具栏、上方通知和配色。

本地与远程栏依次显示标题、路径、合并的筛选与操作栏、文件列表，使用一致的行高。
筛选、隐藏文件切换和操作图标共用 `36` 像素的一行，不再分别占用两行。
两侧表头与列表区域保持对齐，远程连接或断开不会改变列表起始位置。
列表可以独立滚动，表头保持在各自列表顶部。

本地栏在筛选框右侧提供上传和目录选择图标。
选择目录仍使用系统目录选择器；上传仍只接收所选普通文件，未连接、读取中或浏览器预览时禁用。
远程栏保留预览、下载、新建文件夹和删除；空间充足时直接显示复制路径、重命名和属性，
窄窗口将这些次要操作收进「更多文件操作」，保留可用的筛选宽度，不新增一行。
工具栏更多菜单与右键共用操作和禁用规则，保留当前多选目标；图标悬停可查看操作名称。
窄视口通过「本地」「远程」切换文件栏。远程标题旁的扳手为「连接设置」，
打开当前连接的管理菜单；菜单在实际点击的按钮下方展开。

全局保存提示、警告和错误复用底部状态栏，不再在文件列表上方插入通知行；
长内容以省略号显示，可点击查看完整内容，按 Escape、点击外部或再次点击收起，
也可用关闭图标移除。完整内容可滚动和选择复制，不会因截断而丢失。
连接状态与传输速率保留；窄窗口出现提示时暂时让出左侧普通就绪文字的位置。

## 远程文件操作

连接后，远程栏提供后退、前进、上级和刷新，以及文件操作图标；悬停可查看名称。
右键文件会以该文件为目标，右键已选批次保留选择，空白处菜单作用于已打开目录。
菜单中的「刷新目录」只重新读取目录，不再显示会重载页面并丢失会话的 WebView Reload。
输入框和文本预览仍保留系统复制、粘贴等文本菜单。

- 双击普通文件或点击预览图标，在应用内只读查看。UTF-8 文本不超过 1 MiB；
  PNG/JPEG/GIF/WebP 不超过 8 MiB、4000 万像素。二进制、超限文件需下载查看；
  符号链接和特殊文件不预览，HTML/SVG 只作为文本，不执行或嵌入活动内容。
  预览仅在内存中读取，不生成磁盘缓存，不调用外部编辑器，不提供保存回传。
- 下载图标复用现有传输队列，目标为本地栏最后成功打开的目录；
  复制路径可复制单项、多项或当前目录。属性显示路径、类型、大小、时间和服务器提供的权限、UID/GID。
- 新建文件夹使用 `0700` 权限；重命名只改当前父目录内的名称，遇到同名拒绝覆盖。
  重命名仍限单项。删除支持单项和多选批次，只删除普通文件或空目录，不进入回收站、不递归删除。
  根目录、符号链接和特殊文件不能重命名或删除；选择中包含符号链接时不能提交整个批次。
- 多选后，右键任一已选项目的「删除」或点击工具栏删除图标，核对数量和完整路径后确认。
  确认前或取消时不发送删除请求。批次按清单逐项执行，显示待删除、正在删除、已删除和失败原因；
  普通权限、非空目录等失败不影响其他项。有成功项便刷新目录，结果清单不会因刷新而丢失。
  多项全部成功后可关闭结果；单项成功仍自动关闭。部分失败点击「重试失败项」，只提交失败路径，
  不再次处理成功项。删除不是整批事务，部分成功不会自动回滚，也不自动重试。
- 当前连接仍有排队、运行、取消中或同名待处理任务时，需先完成或取消传输再修改远程文件。
  原生队列也进行互斥检查，避免界面状态迟到时与传输并发修改。
  批次中途出现传输或原生操作占用时，停止后续请求并标明未执行项；结束传输后可以重试。
  权限、同名和非空目录错误保留弹窗供修正；断网、超时、会话关闭或切换后不再删除剩余项目，
  不自动在新会话继续。断网或超时后须重连、刷新，确认服务器实际结果，不能直接重试结果不明的请求。

操作使用已接收的目录和精确会话，不使用尚未提交的路径输入。切换连接会关闭旧预览，
并清空远程文件的勾选和菜单，避免两台服务器的同路径文件继承选择；
旧请求的迟到结果不会打开新连接的弹窗。远程修改立即作用于服务器，回退应用版本不会撤销文件改动。

## 上传与下载

1. 连接服务器，并在双栏分别打开本地目录和远程目录。
2. 勾选文件，点击本地栏的上传图标或远程栏的下载图标，也可以拖到另一栏文件列表中。
   拖动已选中的文件会提交当前可见选择；拖动未选中的文件只提交该文件。
   目标是另一栏最后成功打开
   的目录，不是尚未提交的路径输入。目录和符号链接不能作为本阶段的传输来源。
3. 使用复选框多选，或在行上使用 Shift 范围选择、Command/Ctrl 切换选择；
   方向键移动选择，空格切换文件选择，Command/Ctrl+A 选择当前可见的普通文件。
   筛选或切换目录会清理不可见的选择，避免意外传输。
4. 在队列查看进度和失败原因。遇到同名文件会自动弹框，显示文件名和目标路径，
   明确选择「跳过」「覆盖」或「保留两份」；保留两份使用 `文件名 (1).扩展名` 等新名称。
   多个冲突逐个处理，不叠加弹窗；已有连接或认证弹窗时，等待其关闭后再提示。
   关闭冲突弹框表示稍后处理，不提交任何选择，当前已发现的冲突不会因轮询反复弹出；
   可再点击队列中该任务的同名处理图标。提交期间禁止重复点击，失败保留弹框和错误，
   可以重新选择；应用不会默认覆盖已有文件。
5. 使用每行取消或重试图标。取消发生在分块读写边界，阻塞网络操作需等到返回或超时，
   不会切断浏览连接。若最终提交已经开始，任务仍可能完成。重试从头传输，重新检查同名文件，
   不自动覆盖，也不是断点续传。切换服务器不影响原任务，可在队列重试仍连接的后台任务，
   或手动处理其同名冲突；队列和冲突弹窗显示连接名称，操作始终使用任务原来的会话。
   原会话断开或更改认证身份后，旧任务不能借用其他连接重试。

完成后会刷新仍在查看的目标目录；如果该目录正在读取，等读取结束后再补刷。
后台上传的目标保留待刷新标记，切回该连接并查看目标目录时补刷；
不会覆盖其他服务器的列表或尚未提交的路径输入。

双栏拖放复用上述队列、取消、重试和同名处理。放到目录行也仍使用该栏当前目录，
不会进入或上传到那一行的子目录。切换/刷新任一目录、断开/切换连接、Escape、
拖动结束或放到非目标区域后，旧拖动不能再次提交；队列提交期间禁用新的拖放。
macOS Finder 拖入远程栏时只接收普通文件，不接收目录、符号链接、文本、网址或其他
窗口伪造的拖放；一个批次混入不支持项时整批拒绝。Finder 拖出到本地文件夹尚未实现，
也不支持本地栏内复制或移动。
窄视口只显示一栏时使用上传/下载按钮，不能同时拖到隐藏的另一栏。
窗口设置 `dragDropEnabled: true`，由 Tauri 提供 Finder 原生拖放事件；
前端通过 `tauri://drag-enter`、`tauri://drag-over`、`tauri://drag-drop` 和
`tauri://drag-leave` 监听当前 WebView，并把物理像素坐标转换为窗口归一化坐标。
这条原生入口目前只在 macOS capability 上启用；Windows/Linux 的原生拖放和
HTML5 双栏拖放仍需目标环境单独构建、运行和验收，不能由本机测试替代。

传输先写入目标目录内的随机 `.fileworker-*.part` 临时文件，校验长度并关闭后才提交。
默认提交使用不覆盖语义，即使目标在传输途中出现，也不会静默覆盖。
本地明确覆盖通过同目录临时文件替换；远程明确覆盖先将原文件改名为随机
`.fileworker-*.backup`，再提交新文件，失败则尝试恢复原件。远程覆盖不是无间隙原子替换，
短暂缺少目标路径，断网或断电可能留下备份。恢复或清理失败会显示具体路径，
请重新连接后检查；应用不会先删除原文件，也不会自动删除不明临时文件。
有其他进程同时修改目标时，排他提交失败会保留现有文件，必要时保留原文件备份供人工恢复。

正常取消或失败会清理临时文件；网络已中断、强制退出、系统崩溃时无法保证远程清理。
新上传和下载文件默认权限为 `0600`，不复制原权限、修改时间或扩展属性。
源文件大小或修改时间在传输中发生变化会拒绝提交，但不提供源文件快照或内容哈希校验。
本阶段不递归复制文件夹、不跟随源符号链接、不覆盖目录或特殊文件。

队列只保存在当前进程内，每批最多 256 项，总计最多 1000 项。并发设置同样只在本次运行有效；
降低并发不强行中断已经运行的任务。清理已结束任务只删除队列记录，不删除已传输文件。
正常退出会停止调度、取消未结束任务并等待工作线程清理，再统一关闭所有服务器和测试连接；
下次启动不恢复会话或任务。

## SFTP 连接

1. 在桌面应用中点击「新建连接」，填写主机、端口、用户名及可选分组。
   在同一表单直接输入密码，或选择 SSH 私钥文件、粘贴完整私钥内容，并填写私钥口令。
   未加密私钥口令可留空；私钥文件支持绝对路径或 `~/`，默认远程目录 `.` 为服务器主目录。
2. 「测试连接」验证当前草稿，不保存连接配置或凭据，不中断正在浏览的会话和传输。
   首次连接仍需向管理员核对 SHA-256 指纹，明确选择「信任并测试」；
   主机信任记录会保存，已信任指纹变化时阻止认证。测试取消或完成后保留表单输入。
3. 「仅保存配置」不连接、不保存密码或私钥内容；「保存并连接」保存非敏感配置后
   直接使用本次输入连接，首次连接会要求确认指纹。只有明确勾选记住且认证成功后，
   才加密保存到本机；未勾选时仅在本次会话使用。不调用系统钥匙串，
   不要求额外解锁密码，也不回退到明文保存。
4. 侧栏单击选择、双击连接，也可右键连接或使用工作区当前连接菜单；不再显示每项的三点按钮。
   已信任主机且存在凭据时直接认证，不再要求重复点击确认；首次连接仍须核对指纹，
   指纹变化仍阻止连接。无凭据或自动认证失败才提供手工输入，可更换、返回或忘记已存凭据。
   往返切换及认证失败不会清空本次输入；已存秘密由 Rust 读取，不返回界面。
5. 成功后恢复该连接最后成功打开的目录；首次使用配置中的起始目录。
   上次目录不存在或无权限时提示并仅尝试回到起始目录；断网不会触发回退循环。
   相对路径以最后成功打开的目录为基准，符号链接与 `..` 由服务器解析；
   空路径提交刷新当前目录，无权限时仍可返回上级或重试。
6. 切换侧栏连接只更换远程工作区，不断开已有会话；再次选择时保留各自目录和导航历史，
   双击已连接对象不会重复认证。后台传输继续，未连接的对象仍须双击或点击连接后才建立会话。
   未完成的握手或认证仍是单一前台操作，切换离开会取消该次尝试，不影响已认证连接。
7. 点击断开图标只结束当前会话，其他服务器继续连接；正常退出 App 时统一断开。
   网络中断或服务器空闲超时仍可能断开，需要重新连接，本版本不自动重连。
   「忘记已存凭据」只删除该身份的新本地加密条目，
   不删除配置、主机信任记录或服务器文件，也不使已连接会话失效。
   删除连接或修改主机、端口、用户名、认证方式、私钥路径时，会取消旧认证并清理旧凭据；
   清理失败不会写入新配置。若后续磁盘写入失败，原配置保留，但可能需要重新输入凭据。

连接可右键编辑、复制或删除；复制只复制配置，不复制密码。
有未完成传输也能自由切换或连接其他服务器。只有断开、重连、删除或修改该连接的认证身份时，
需先结束或取消它自己的任务；编辑、删除后台连接也遵守同一规则。
改名、调整分组和默认目录不重置会话。标题栏的「文件工作区」与空白区域可拖动窗口。
删除连接或修改主机、端口、用户名、默认目录会清除该连接的目录记忆；
改名、分组不清除。目录记忆只在目录成功读取后更新，不记录失败请求或未提交的输入。
它存于 WebView 本地键 `fileworker.remote.last-path.v1:<连接ID>`，包含端点元数据和路径，
不含密码，不写入连接配置，也不跨设备同步；损坏记录保留且忽略，存储不可用不影响浏览。

### 连接分组

侧栏「我的连接」旁的文件夹加号创建分组，例如生产、测试。点击分组箭头展开或折叠，
更多菜单可在组内新建连接、改名或删除组；编辑连接时也可随时改到另一组或「未分组」。
当前为单层分组，不支持嵌套；删除组保留全部连接与凭据，连接移至未分组。
分组与连接均按原有顺序显示，修改名称不改变位置。

折叠状态单独保存在 WebView 的 `fileworker.groups.collapsed.v1` 中，重启保留；
不写入连接配置，不跨设备同步。后续主动选择或移动连接时会展开目标组，
但启动恢复默认选择不会覆盖此前手动折叠。

载入或切换连接配置后可立即连接；旧连接的迟到握手结果不会恢复旧表单，也不会取消新尝试。

默认网络操作超时为 15 秒，待认证连接有效期为两分钟，过期后需重新连接。
本地凭据库的跨进程锁最多等待两秒，超时提示存储不可用；同一凭据的操作保持串行。
保存失败不会中断已认证的连接。保存尚未提交为有效会话便被取消时，会恢复原有凭据；
存储无法恢复时会返回说明。已完成的保存或主机信任不会因之后断开而自动忘记。
当前仅支持密码和私钥认证，不支持 SSH Agent、键盘交互式认证或多因素认证。

## 配置与安全

桌面连接配置位于：

```text
~/Library/Application Support/com.fileworker.desktop/profiles.json
```

数据结构为 `{ "version": 2, "groups": [...], "profiles": [...] }`，
连接的可选 `groupId` 引用分组；`privateKeyContent` 认证方式只标识私钥来源，不保存私钥。
版本 `1` 仍可读取；第一次有效写入前创建原字节备份 `profiles.v1.backup.json`，随后写为
版本 `2`。备份不会覆盖已有文件，备份失败则保留旧配置，不继续迁移。
回退旧应用前先退出并保留现用版本 `2` 文件，再从该版本 `1` 备份恢复；
备份仅包含迁移时的连接，后续新增、修改和分组不会自动迁回旧版。

配置模型拒绝密码、私钥内容和口令等未知字段。前端输入仅保留在表单临时状态，
通过独立认证参数传给 Rust，不写浏览器存储或配置，不把已保存秘密返回界面。
为独立传输连接复用认证，Rust 在活动会话内存中以 `Zeroizing` 保留本次密码或私钥凭据，
不要求保存到磁盘。断开立即使会话失效；正在认证的线程释放最后引用后会零化秘密。
忘记已存凭据只移除对应的本地加密条目，不使当前已认证会话失效。
损坏、包含未知字段或版本不受支持的配置会报错，不会被静默重置。
新建目录权限为 `0700`，配置文件权限为 `0600`。
配置读改写事务由同目录 `profiles.lock` 文件锁串行化，防止多个实例互相覆盖新增连接。
锁文件不保存凭据；进程退出后由操作系统释放锁。
多个窗口不会实时同步列表，需要重新打开应用才能重新读取其他实例的改动。

本地浏览只读取目录；只有主动提交的下载任务才创建文件，明确选择覆盖后才替换已有文件。
遇到目录访问错误会显示错误；个别文件信息读取失败会显示警告数量。

远程主机信任记录单独保存在应用数据目录的 `known_hosts.json`，不使用也不修改用户的
`~/.ssh/known_hosts`。应用专用记录使用主机名和端口区分，写入前通过锁文件串行化并
使用临时文件替换；损坏记录不会被静默覆盖。本地凭据库中的条目
由连接配置和认证身份计算，不包含可读的主机名或用户名。
条目绑定配置 ID、主机、端口、用户名、认证方式和私钥路径；改名、分组或默认目录不改变绑定。
身份散列格式不变，但旧 Keychain 凭据不迁移：升级后请手动输入一次并勾选记住。
应用不读取、删除或回退访问旧 Keychain 条目。
修改认证身份或删除配置会先取消旧认证，等待相关凭据操作完成并移除旧条目，
避免迟到保存重新留下凭据；不会在访问凭据时持有配置文件锁。
单次磁盘读写使用跨进程锁和原子替换；取消/配置变更的完整流程协调仍限定于单进程，
不建议多个应用实例同时编辑同一连接。
浏览器预览不会发起 SSH、读取本地凭据库或保存密码；预览配置以原子单文档键
`fileworker.preview.connections.v2` 保存，旧 `fileworker.preview.profiles.v1` 仍可读取并保留，
仅用于独立预览，不与桌面配置同步。

### 本地加密凭据

首次勾选记住且认证成功后，在应用数据目录创建 `credentials-v1/`。
macOS 路径为 `~/Library/Application Support/com.fileworker.desktop/credentials-v1/`。
其中 `master.key` 是随机生成的安装密钥，`store.lock` 用于事务锁，
`<身份散列>.enc` 是独立密文。密码、私钥文件口令和粘贴私钥均使用
XChaCha20-Poly1305；每次保存生成新随机 nonce，并认证绑定版本和连接身份。
单条秘密上限为 8 MiB；状态查询不解密秘密，未保存时不会创建凭据目录。
Unix 目录/文件分别为 `0700`/`0600`，拒绝不安全权限、链接及非普通对象；
Windows 计划依赖当前用户应用数据目录的继承 ACL，尚未原生验收。

**自动使用有安全取舍：解密密钥也在本机，能读取密钥和密文的人就能解密。**
这不是钥匙串级别的隔离，不防当前用户、管理员或本机恶意程序，也没有主密码。
不要把凭据库上传 Git、云盘或公开分享；备份须保护整套密钥和密文。
仅复制密文无法恢复密码，丢失密钥无法找回；损坏、未知版本、错误密钥不会自动重置或覆盖原条目。
需要重存损坏条目时先明确选择忘记；密钥异常应先保留备份再排查，不要盲目删除密钥文件。
忘记最后一条后仍保留原密钥，避免其他实例或后续保存意外换钥。

回退到 `preview.8` 使用原来的 Keychain，与新库互不同步；
新保存的秘密不会回写旧版。连接配置、主机信任、目录记忆和外观格式不变。
这里的本地跨平台存储实现不代表 Windows/Linux 应用已完成支持。

`Cargo.toml` 将 `libssh2-sys` 固定到 `ssh2-rs` 上游提交
`60b9c193bcf0511aa569d1408a92fd3ba803f4b7`，修复服务端重复签名算法触发的 C
堆越界；不要在未运行相应协议回归与 C AddressSanitizer 检查时移除该固定。
